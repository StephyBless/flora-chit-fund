# 🌸 FLORA CHIT FUNDS - Management System

## 📌 Overview

**FLORA CHIT FUNDS** is a modern web-based chit fund management system designed to simplify member tracking, payment management, and financial monitoring.

This application provides an intuitive dashboard to manage members, track payments, calculate pending amounts, and send automated WhatsApp notifications.

## ✨ Key Features

### 👥 Member Management

* Add, edit, and delete members
* Store member details (name, phone number, chit amount)
* Maintain payment history

### 💰 Payment Tracking

* Record installment payments
* Automatic calculation of:

  * Total paid
  * Remaining amount
* Status tracking:

  * ✅ Paid
  * ⚠️ Partial
  * ❌ Pending

### 📊 Dashboard Analytics

* Total members count
* Total collected amount
* Total pending amount

### 🔍 Smart Search

* Search members by name or phone number

### 📱 WhatsApp Integration

* Automatically send payment updates to members via WhatsApp

### 🎨 Modern UI/UX

* Responsive design (mobile-friendly)
* Gradient-based aesthetic interface
* Smooth animations and transitions

---

## 🛠️ Tech Stack

* **Frontend:** HTML, CSS, JavaScript
* **Storage:** Browser LocalStorage
* **UI Design:** Custom CSS (Glassmorphism + Gradients)
* **Integration:** WhatsApp API (via URL scheme)

---

## ⚙️ How It Works

1. Add members with chit details
2. Store data in browser localStorage
3. Update payments via modal interface
4. System calculates remaining balance automatically
5. Dashboard updates in real-time
6. WhatsApp notification is triggered after payment update
